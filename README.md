# Cisco Packet Tracer Labs

This repository contains basic Cisco Packet Tracer networking labs created for learning computer networking concepts.

## 📚 About

The purpose of this repository is to practice and understand fundamental networking devices and their functions using Cisco Packet Tracer.

## 🗂 Lab Files

| File Name | Description |
|------------|------------|
| Router.pkt | Basic router configuration and operation |
| Switch.pkt | Basic switch configuration and connectivity |
| Hub.pkt | Demonstration of a network hub |
| Repeater.pkt | Demonstration of a repeater in a network |
| connecting_2_PC.pkt | Connecting two PCs and testing communication |
| hub and switch.pkt | Comparison and implementation of hub and switch connectivity |

## 🎯 Learning Objectives

- Understand network devices and their functions
- Learn how routers forward packets between networks
- Learn how switches connect devices within a LAN
- Understand the role of hubs and repeaters
- Practice basic network topology creation
- Test network communication using Packet Tracer

## 🛠 Software Used

- Cisco Packet Tracer

## 🚀 How to Use

1. Install Cisco Packet Tracer.
2. Clone this repository:

```bash
git clone https://github.com/kavinadee2/Cisco.git
```

3. Open any `.pkt` file using Cisco Packet Tracer.
4. Explore the topology and configurations.
